# Traveltures - Site de Viagem

Traveltures é um site desenvolvido para explorar destinos de viagem ao redor do mundo. O projeto foi construído utilizando **HTML**, **CSS** e **Bootstrap**, oferecendo uma experiência de navegação responsiva e agradável para os usuários.

## Funcionalidades

- **Página Inicial**: Apresenta uma lista de destinos populares com links para mais informações.
- **Página de Destino**: Descrição detalhada de um destino turístico, com fotos, pontos turísticos e dicas de viagem.
- **Responsividade**: O site foi desenvolvido para ser totalmente responsivo, adaptando-se a diferentes tamanhos de tela (desktop, tablet, celular).
- **Design Atraente**: Utilização do framework **Bootstrap** para garantir um design moderno e funcional.
- **Estilo Personalizado**: Customização dos componentes padrão do Bootstrap com **CSS** para atender às necessidades específicas do projeto.

## Tecnologias Utilizadas

- **HTML5**: Estruturação da página.
- **CSS3**: Estilização personalizada.
- **Bootstrap**: Framework CSS para criar uma interface responsiva e moderna.

## Como Rodar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/GuilhermeAquinoDB/traveltures.git

2. Acesse o diretório do projeto:
   ```bash
   cd traveltures

3. Abra o arquivo index.html em seu navegador para visualizar o site.
